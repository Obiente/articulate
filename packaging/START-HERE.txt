ARTICULATE
Your words, ready to use.

Windows 10/11, 64-bit Intel or AMD. No account or subscription.
The installer runs for your Windows user and needs no administrator access.
For the portable ZIP, extract the whole folder before opening Articulate.exe.
Keep all DLLs beside the app.
The interface requires Microsoft Edge WebView2 Evergreen Runtime. Setup checks
for it and opens Microsoft's download page if it is missing. For the portable
ZIP, install the runtime before opening the app if Windows does not have it:
https://developer.microsoft.com/microsoft-edge/webview2/#download-section
Node.js and a development server are not needed to run Articulate.

FIRST START
1. Open Settings and choose Download model (about 2.19 GB).
2. Choose your microphone. Use headphones for call transcripts.
3. Hold Ctrl+Alt+Space to dictate. Release to finish. Double-press for
   hands-free recording, then press once to finish. Settings offers toggle
   mode, custom keys, and optional start/stop sounds.
4. Enable Insert into your app and focus its text field before dictating.
   Hold mode inserts after finishing. Toggle mode can type live in supported
   fields. Test in a disposable text field first.
5. For calls, open Notetaker > Record a conversation. The companion needs its separate
   audio connection. For other apps, choose mixed output capture and download
   speaker identification (about 237 MB) when activity names are unavailable.

Large speech models download separately. Small Assort notes and vocabulary
models are included. Initial speech-model downloads require internet.
Recognition works locally after download. A recent PC with 16 GB RAM is
recommended; CPU-only operation is supported. If GPU loading fails, choose
CPU only in Settings. First GPU loading can take longer while it warms up.

LOCAL TEXT CLEANUP
Finished dictation receives local cleanup before insertion. Original
transcripts remain available in the library.

UPDATES
Download updated installers from github.com/Obiente/articulate/releases.
Finish any recording before installing. Models and saved sessions are kept.
This initial release is not code-signed. Windows may show an unknown-publisher
warning. Obtain builds only from github.com/Obiente/articulate/releases.

YOUR DATA
Transcripts, notes, vocabulary, preferences and models are stored under
%LOCALAPPDATA%\TranscribeLocal. Audio is not saved. Uninstalling keeps this data.
There is no cloud transcription, telemetry, account or automatic sync.

NOTETAKER
Choose New note to write without a microphone or model. Personal notes save
automatically. Open a conversation to switch between its notes document and
its transcript. Notes can update during a call when the notes model is ready.
The active conversation card returns to capture without restarting it.

CALLS AND DISCORD
Output capture includes everything playing through the chosen device.
The Vencord companion includes an adapter for separate participant audio.
Capture waits for that connection rather than silently using mixed audio.
Live callback behavior still needs validation on supported Discord builds.
The debugger connection provides activity names only and cannot separate
overlapping mixed audio. See docs/vencord.md in the repository.
Review generated notes against the transcript before relying on them.

FEEDBACK
Use github.com/Obiente/articulate/issues. Include app version, Windows version,
CPU/GPU, and steps to reproduce. For recognition problems, include a short
synthetic or non-sensitive example and what you expected. Review any screenshot
or transcript for private content before sharing it.

Licenses for the app, runtime, fonts and dependencies are in licenses/.

SUMMARIES AND INSIGHTS
Download the optional summary model in Settings (about 3.16 GB on first setup).
Open a saved conversation and use Update notes to generate a notes document.
Notes and the transcript stay separate. Search finds phrases in saved content.
Insights shows your retained dictation usage on this device.
